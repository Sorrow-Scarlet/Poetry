# FSharp.Core.Dll

![HeadImage](./About/Preview.png)

A F# Core inspired by [alattalatta/Monoworld](https://github.com/alattalatta/Monoworld/blob/main/Poet).

## Dev

Debug:

```bash
dotnet build
```

Release:

```bash
dotnet publish
```

Pack:

```bash
dotnet publish
dotnet fsi pack.fsx
```

> [!NOTE]
